## Secuencia inferencial, no temporal

```text
muestra → medición → calendario → contexto → fase → acontecimiento
```

Las flechas representan pruebas, no paso del tiempo. Un objeto antiguo puede depositarse tarde; una fase puede durar generaciones; una institución puede surgir gradualmente; una publicación nueva puede revisar una distribución antigua.

## Sincronismos: transferencia condicionada

| Sincronismo | Requisito mínimo | Riesgo circular |
|---|---|---|
| texto–objeto | procedencia y contemporaneidad | usar el nombre para fechar la fase y luego la fase para validar el nombre |
| anillo–edificio | borde/uso demostrados | tratar tala como construcción |
| tefra–archivo | huella y deposición primaria | usar la edad del archivo objetivo para identificar la tefra |
| evento astronómico–texto | fenómeno/calendario/observación únicos | seleccionar la solución que confirma cronología previa |
| lista real–fase | transmisión, lagunas y correspondencia | imponer sucesión sin corregencias |

## Regla de lectura

Una cronología gana resolución sólo cuando conserva las dependencias que produjeron esa resolución. Si dos resultados comparten curva, contexto, prior o sincronismo, no se cuentan como dos verificaciones totalmente independientes.
