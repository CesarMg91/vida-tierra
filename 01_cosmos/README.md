## Regla específica del módulo

Cada investigación debe separar:

- el fotón o partícula detectado hoy;
- la propiedad instrumental calibrada;
- la física local probada en laboratorio;
- la geometría o modelo astrofísico;
- la afirmación sobre una época remota;
- los primeros planos, selección y dependencia entre datasets.

Un telescopio no “ve el Big Bang”, la nucleosíntesis o la edad. Registra señales que adquieren significado dentro de una cadena contrastable.
