# 15 — Medicina

Esta serie estudia cómo se construye y limita el conocimiento clínico. No sustituye la valoración profesional, no recibe datos de pacientes y no publica recomendaciones terapéuticas individualizadas.

## Estándar de la serie

- [`ESTANDAR_EVIDENCIA_CLINICA.md`](ESTANDAR_EVIDENCIA_CLINICA.md): contrato editorial para preguntas, efectos, daños, aplicabilidad y actualización.

## Investigaciones auditadas

- [`INV-MED-INTERVENTIONS-001`](INVESTIGACION_MED_001_INTERVENCIONES_EFICACIA_DANOS.md) — cómo sabemos si una intervención médica o quirúrgica funciona, para quién y con qué daños — **AUDITADO**.

La línea temática usa el subíndice `MED` y no altera la secuencia global `001–052` ni la línea `CIV`. Cada expediente declara población, intervención, comparador, desenlaces, tiempo, estimando, sesgos, daños, aplicabilidad y fecha de corte.
