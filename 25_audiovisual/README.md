# Audiovisual

Guiones y normas para la serie en vídeo derivada de las investigaciones.

Como el libro de [`../24_libro`](../24_libro/README.md), esto es una **vista narrativa derivada**, no una capa canónica. Si un guion contradice un registro maestro, se corrige el guion o se abre una revisión del claim. No se mantienen dos verdades.

## Hilo de la serie

El **circón**. Un cristal real de 4.404 Ma, físicamente continuo a través de toda la historia profunda, que al final resulta ser la prueba que examinamos bajo el microscopio.

No es una licencia poética: es el objeto de `CLAIM-HADEAN-ZIRCON-001`. Se eligió precisamente para evitar el recurso narrativo de «un ser atravesando las etapas», que reproduce la marcha del progreso y contradice lo que sostienen las investigaciones 032, 033 y 036: la sucesión cronológica no demuestra genealogía.

## Regla de una línea

> Nada que sostenga una afirmación puede estar generado por IA.
