# Plantillas

Copiar la plantilla pertinente al directorio temático, sustituir todos los campos entre `< >` y eliminar instrucciones no aplicables explicando por qué. Las plantillas no son formularios burocráticos: obligan a que la prosa conserve trazabilidad.

| Plantilla | Uso |
|---|---|
| `TEMPLATE_INVESTIGACION.md` | pregunta profunda completa |
| `TEMPLATE_CLAIM.md` | desarrollo de una afirmación |
| `TEMPLATE_EVIDENCIA.md` | objeto, muestra o dataset |
| `TEMPLATE_FUENTE.md` | auditoría bibliográfica |
| `TEMPLATE_CONTROVERSIA.md` | comparación de explicaciones |
| `TEMPLATE_ERROR_CIENTIFICO.md` | caso histórico de corrección |
| `TEMPLATE_EVENTO_CRONOLOGICO.md` | evento en cronología |
| `TEMPLATE_MAPA_EPISTEMOLOGICO.md` | dependencias entre inferencias |
| `TEMPLATE_FICHA_ESPECIE.md` | taxón fósil/humano |
| `TEMPLATE_TRANSICION_EVOLUTIVA.md` | innovación biológica |
| `TEMPLATE_INFORME.md` | síntesis fechada |
| `TEMPLATE_CAPITULO_LIBRO.md` | narrativa derivada |
