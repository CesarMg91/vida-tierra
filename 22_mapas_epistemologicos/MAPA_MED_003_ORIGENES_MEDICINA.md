# Mapa epistemológico MED-003 — De una huella a una historia médica

~~~text
espécimen / objeto / texto
            ↓ autenticidad + procedencia
         contexto
            ↓ fecha + asociación + tafonomía
          huella
            ↓ descripción + controles
   diferencial / interpretación
            ↓ comparación + alternativas
         conducta
            ↓ dependencia / técnica / transmisión
      sistema médico
            ↓ roles + institución + consecuencias
~~~

## Productos que no deben colapsarse

| Archivo | Producto fuerte | Producto condicionado | No demostrado sin otra capa |
|---|---|---|---|
| hueso remodelado | respuesta vital y supervivencia | limitación funcional | tratamiento, motivo o eficacia |
| defecto compatible | geometría y proceso probable | intervención intencional | indicación y resultado buscado |
| cálculo dental | material atrapado y microbioma oral | exposición o dieta parcial | automedicación y dosis |
| ADN patógeno | presencia autenticada | infección bajo contexto convergente | síntomas, causa de muerte o prevalencia |
| paleofeces | contenido de una deposición | microbioma intestinal antiguo | salud de una población |
| objeto | manufactura, residuo y asociación | uso situado | profesión o eficacia |
| texto | categoría, receta o norma | práctica bajo corroboración | diagnóstico moderno o uso general |

## Cortafuegos

- supervivencia ≠ curación;
- dependencia ≠ compasión demostrada;
- ausencia de una parte ≠ amputación por sí sola;
- remodelación ≠ tasa clínica comparable;
- presencia molecular ≠ enfermedad;
- primera detección ≠ origen;
- planta en la boca ≠ medicamento;
- receta escrita ≠ tratamiento usado;
- práctica documentada ≠ eficacia;
- archivo ausente ≠ conducta ausente;
- más tarde ≠ más avanzado.

## Convergencia legítima

~~~text
hueso + contexto + comparación funcional     → asistencia probable
marca + geometría + experimento + remodelado → intervención apoyada
ADN + daño antiguo + controles + filogenia   → presencia autenticada
texto + filología + objeto + contexto        → práctica mejor situada
~~~

Las flechas expresan productos auditables, no certezas universales. Cada resultado conserva escala, alternativas y falsadores.
