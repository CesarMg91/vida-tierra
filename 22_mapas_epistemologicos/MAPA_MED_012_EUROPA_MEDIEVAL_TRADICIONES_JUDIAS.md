# Mapa epistemológico MED-012 — Un currículo no hereda una consulta

## Pregunta

¿Qué transformación permite pasar de un objeto medieval a una afirmación sobre cuidado sin colapsar copia, enseñanza, autorización, encuentro y consecuencia?

## Cadena principal

**testigo → versión → currículo → practicante → encuentro → alcance**

| Nodo | Observación mínima | Operación | Inferencia válida | Cortafuego |
|---|---|---|---|---|
| testigo | códice, estatuto, contrato, regla, edificio | procedencia y crítica material | existe este producto | conservación ≠ representatividad |
| versión | texto, glosa, traducción, ensamblaje | filiación y comparación | esta lectura estuvo disponible | versión ≠ fidelidad |
| currículo | lista, comentario, examen, licencia | historia institucional | esta autoridad fue prescrita | norma ≠ aprendizaje |
| practicante | nombre, título, pago, vínculo | prosopografía | este agente actuó o fue reconocido | identidad ≠ método |
| encuentro | consulta, receta, operación, cuidado | reconstrucción de episodio | ocurrió un acto delimitado | episodio ≠ frecuencia |
| alcance | acceso, daño, seguimiento, población | comparación y denominador | efecto o límite observado | presencia ≠ beneficio |

## Caso A — códices, monasterios y hogares

**Ruta:** Royal MS 12 D XVII → libros y adiciones → procedencia → operación posible → uso abierto → resultado abierto.

- Archivo: un códice de pergamino con colecciones diferentes.
- Observado: remedios, diagnósticos, encantamientos y una adición marginal.
- Inferencia: repertorios copiados y modificados.
- Alternativas: consulta, biblioteca, enseñanza, intercambio o prestigio.
- Límite: el monasterio que conserva no identifica cada lugar de ejecución.

Claims: CLAIM-MED-MEDIEVAL-MONASTIC-MIXED-001, CLAIM-MED-MEDIEVAL-RECIPE-PRACTICALITY-001 y CLAIM-MED-MEDIEVAL-HOUSEHOLD-CARE-001.

## Caso B — Trotula y participación femenina

**Ruta:** manuscritos → tres obras → atribuciones → lectores/practicantes → cuidado → alcance.

- Archivo: 122 manuscritos latinos y 52 versiones vernáculas estudiadas.
- Observado: ensamblaje de tres textos con historias diferentes.
- Inferencia: Trota se relaciona con una parte temprana.
- Alternativas: atribución editorial, autoridad nominal y reescritura.
- Límite: texto sobre mujeres no es voz directa ni censo laboral.

Claims: CLAIM-MED-MEDIEVAL-TROTULA-ENSEMBLE-001, CLAIM-MED-MEDIEVAL-TROTA-ATTRIBUTION-001 y CLAIM-MED-MEDIEVAL-WOMEN-PRACTICE-001.

## Caso C — traducción y reescritura

**Ruta:** obra fuente → traducción → revisión → repertorio docente → lector → uso.

- Archivo: *Pantegni*, listas toledanas y versiones hebreas.
- Observado: selección, condensación, clarificación y adaptación.
- Inferencia: circulación transformativa entre lenguas.
- Alternativas: programa autoral, patronazgo, enseñanza o audiencia.
- Límite: lengua no fija religión; traducción no prueba práctica.

Claims: CLAIM-MED-MEDIEVAL-TRANSLATION-NETWORK-001, CLAIM-MED-MEDIEVAL-PANTEGNI-VERSION-001 y CLAIM-MED-MEDIEVAL-HEBREW-TRANSLATION-001.

## Caso D — universidad y licencia

**Ruta:** Articella → comentario → currículo local → examen → licencia → práctica.

- Archivo: manuscritos, glosas, estatutos y autorizaciones.
- Observado: colecciones y programas variables.
- Inferencia: institucionalización parcial de medicina letrada.
- Alternativas: aprendizaje privado, cirugía, hogar y empirismo.
- Límite: universidad no monopoliza cuidado; licencia no mide resultado.

Claims: CLAIM-MED-MEDIEVAL-ARTICELLA-CURRICULUM-001, CLAIM-MED-MEDIEVAL-UNIVERSITY-PRACTICE-001, CLAIM-MED-MEDIEVAL-LICENSING-LOCAL-001 y CLAIM-MED-MEDIEVAL-PRACTITIONER-CONTINUUM-001.

## Caso E — cirugía y hospital

**Ruta:** tratado/regla → opción → agente → intervención/cuidado → seguimiento → consecuencia.

- Archivo: pasajes quirúrgicos, fundaciones y reglas.
- Observado: técnicas, abstenciones, deberes y recursos.
- Inferencia: repertorio de decisión y programa de cuidado.
- Alternativas: reputación, riesgo, caridad, oración o alojamiento.
- Límite: no hay denominador suficiente para eficacia o cobertura.

Claims: CLAIM-MED-MEDIEVAL-SURGERY-TEXT-001, CLAIM-MED-MEDIEVAL-SURGERY-CHOICE-001, CLAIM-MED-MEDIEVAL-HOSPITAL-CHARITY-001 y CLAIM-MED-MEDIEVAL-HOSPITAL-VARIATION-001.

## Caso F — practicantes judíos

**Ruta:** contrato/licencia → identidad situada → servicio → paciente → jurisdicción → alcance.

- Archivo: notarios, tribunales, salarios, traducciones y prohibiciones.
- Observado: médicos judíos atendieron en redes compartidas y desiguales.
- Inferencia: participación, negociación y movilidad locales.
- Alternativas: demanda, patronazgo, aprendizaje familiar o excepción.
- Límite: identidad no determina método, habilidad o tolerancia.

Claims: CLAIM-MED-MEDIEVAL-JEWISH-PRACTITIONERS-001 y CLAIM-MED-MEDIEVAL-JEWISH-NONESSENCE-001.

## Estados epistemológicos

| Estado | Significado |
|---|---|
| observado | el objeto o acto está documentado |
| inferencia permitida | operación apoyada por procedencia y contraste |
| condicional | depende de un eslabón explícito todavía parcial |
| no demostrado | el producto requerido no existe o no basta |
| evidencia contraria | un caso debilita la generalización |
| dato ausente | el archivo no permite decidir |

## Cortafuegos activos

- Europa medieval ≠ sociedad, Iglesia, lengua o medicina únicas.
- judío ≠ hebreo ≠ árabe ≠ método clínico.
- procedencia monástica ≠ uso monástico.
- receta practicable ≠ receta ejecutada.
- texto sobre mujeres ≠ voz de todas las mujeres.
- Trota ≠ autoría de todo el *Trotula*.
- traducción ≠ copia, comprensión o aplicación.
- currículo ≠ consulta.
- licencia ≠ competencia o cumplimiento.
- título ≠ función fija.
- cirugía descrita ≠ cirugía exitosa.
- hospital ≠ clínica moderna.
- prohibición ≠ obediencia universal.
- contrato ≠ representatividad.
- circulación ≠ eficacia.

## Evidencia adversaria que debe permanecer visible

| Generalización tentadora | Archivo adversario |
|---|---|
| todo texto monástico fue usado en enfermería | procedencia y lugar de ejecución divergen |
| Trotula fue una autora única | tres obras y genealogías distintas |
| traducción preservó íntegro el original | abreviación y revisión del *Pantegni* |
| universidad monopolizó medicina | continuo urbano de practicantes |
| licencia creó profesión uniforme | reglas locales y excepciones |
| cirujano letrado siempre operaba | abstenciones de Guy de Chauliac |
| hospital medieval era centro clínico | hospitalidad, caridad y oración dominantes en varias casas |
| médicos judíos estaban siempre excluidos o siempre privilegiados | prohibiciones y contratos coexistentes |

## Dependencias

- MED-001 define efecto, daño, comparador y aplicabilidad.
- MED-002 define utilidad diagnóstica y decisiones.
- MED-004 a MED-011 aportan crítica de documentos, corpus, cánones, instituciones y traducciones.
- CIV-002 separa fecha del objeto, fase y acontecimiento.

## Estado final

- **AUDITADO:** testigos, composición textual, traducciones, currículos, contratos, reglas y agentes seleccionados.
- **CONDICIONAL:** uso de recetas, práctica doméstica, ejecución curricular, cobertura institucional y representatividad profesional.
- **NO DEMOSTRADO:** eficacia poblacional, monopolio universitario, licencia universal, hospital clínico moderno, esencia médica religiosa o relevo civilizatorio.
