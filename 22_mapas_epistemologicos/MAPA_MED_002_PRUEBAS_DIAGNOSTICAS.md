# Mapa epistemológico MED-002 — Una prueba dentro de una ruta

```text
población + uso previsto + condición objetivo
                     ↓
          prueba índice + umbral
                     ↓ lectura independiente
        referencia + intervalo temporal
                     ↓ verificaciones e indeterminados
     tabla / distribución / calibración
                     ↓ incertidumbre + riesgo de sesgo
     probabilidad posterior o clasificación
                     ↓ acción definida + comparador
          consecuencias para pacientes
```

## Seis niveles que no deben colapsarse

| Nivel | Objeto observado | Inferencia permitida | Salto ilegítimo |
|---|---|---|---|
| detección | señal, imagen, analito o patrón | el sistema produjo una observación | la condición existe |
| exactitud | concordancia frente a referencia | rendimiento en población y umbral estudiados | rendimiento universal |
| probabilidad | riesgo posterior dentro de una ruta | actualización condicionada al contexto | certeza individual |
| manejo | cambio de clasificación o acción | la información alteró decisiones | la decisión fue beneficiosa |
| utilidad | beneficios, daños, carga y uso de recursos | balance frente a alternativa | beneficio fuera del contexto |
| desenlace | resultado importante para pacientes | efecto de la estrategia estudiada | mecanismo único o indicación permanente |

## Cortafuegos

- señal detectable `≠` condición clínicamente relevante;
- referencia habitual `≠` verdad perfecta;
- sensibilidad alta `≠` prueba útil para cualquier propósito;
- especificidad alta `≠` valor predictivo alto en cualquier población;
- AUC alta `≠` calibración correcta;
- validación interna `≠` transportabilidad;
- asociación `≠` utilidad;
- diagnóstico más temprano `≠` vida prolongada;
- cambio de estadio `≠` reducción de mortalidad;
- menos pruebas `≠` mejor resultado sin vigilar fallos y daños;
- checklist completo `≠` bajo riesgo de sesgo;
- algoritmo bloqueado `≠` desempeño estable después del despliegue.

## Diseños alineados con preguntas

```text
exactitud          → cohorte con índice y referencia comparables
comparación        → pruebas emparejadas o asignación entre rutas
cambio de manejo   → estudio de impacto con acciones predefinidas
beneficio/daño     → ensayo de estrategia prueba-tratamiento
modelo predictivo  → desarrollo separado de validación externa
implementación     → vigilancia de deriva, equidad y consecuencias
```

La elección del diseño precede a la métrica. Ninguna celda autoriza consejo para una persona ni sustituye una guía clínica vigente.
