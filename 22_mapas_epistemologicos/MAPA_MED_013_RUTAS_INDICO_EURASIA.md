# Mapa epistemológico — Rutas del Índico y Eurasia

## Pregunta operativa

¿Qué puente adicional exige cada salto entre un objeto conectado y una transformación médica?

## Cadena principal

```text
HUELLA
  objeto · residuo · folio · carta · inventario · regalo · libro
    │ procedencia, fecha y asociación
    ▼
IDENTIFICACIÓN
  material · sustancia · versión · lengua · género · agente
    │ alternativas y resolución
    ▼
ITINERARIO
  origen compatible · tramo · nodo · destino narrado · intervalo
    │ evidencia de conexión, no carretera completa
    ▼
MEDIACIÓN
  transportar · comprar · traducir · regalar · compilar · imprimir
    │ selección, poder y pérdida
    ▼
RECEPCIÓN
  leer · glosar · preparar · prescribir · adaptar · rechazar
    │ episodio observable
    ▼
ALCANCE
  audiencia · población · práctica · continuidad · resultado
```

Una flecha sólo se conserva si existe evidencia independiente para el puente. Si no existe, el estado correcto es **no demostrado**, no una línea punteada presentada como hecho.

## Productos y falsos herederos

| Producto observado | Inferencia defendible | No hereda |
|---|---|---|
| casco y cargamento asociados | conexión marítima y transporte | destino, función médica o entrega |
| señal química compatible | identidad material probable | nombre histórico, indicación o eficacia |
| folio multilingüe | versión y encuentro textual | médico viajero o sistema completo |
| carta mercantil | relación, tramo y mercancía | prescripción o administración |
| lista de botica | disponibilidad registrada | venta, paciente o dosis |
| prescripción | decisión escrita | preparación, adherencia o beneficio |
| regalo cortesano | entrega narrada y prestigio | consumo o resultado |
| traducción | versión nueva | fidelidad, comprensión o adopción |
| oficina imperial | capacidad institucional | cobertura o homogeneidad |
| edición impresa | publicación y selección | descubrimiento único o verdad |

## Seis rutas de prueba

### 1. Belitung

```text
pecio → tecnología/carga → tramo marítimo → mercaderes y tripulación no individualizados
      → recepción interrumpida por naufragio → función médica no demostrada
```

Control: resinosa no significa farmacéutica. Calafateo, perfume, incienso y mercancía compiten.

### 2. Dunhuang

```text
folio → texto/diagrama tibetano → frontera multilingüe → copia/adaptación
      → paralelos y diferencias → alcance práctico abierto
```

Control: semejanza puede proceder de convergencia, fuente común o varios préstamos; un nombre tardío no repara cronología.

### 3. Geniza

```text
carta/lista/receta/cuaderno → género → tramo o repertorio → mercader/escriba/practicante
                            → decisión según documento → resultado rara vez enlazado
```

Control: no unir fragmentos por pertenecer a la misma colección moderna.

### 4. Regalos y azúcar

```text
relato/receta → objeto o versión → donante/receptor o genealogía → diplomacia/traducción
              → entrega/adaptación → administración y efecto abiertos
```

Control: una fórmula similar puede tener fuente común o ingredientes convergentes.

### 5. Imperios mongoles

```text
compilación/oficina → repertorio identificado → corte o corredor → especialista/traductor/patrono
                    → selección documentada → alcance social desigual
```

Control: coexistencia no es síntesis; patrocinio no es cobertura.

### 6. Goa y Orta

```text
edición de 1563 → entrada/nombre/descripción → Goa y redes del Índico → informantes/autor/impresor
                → libro y adaptación latina → lectura y práctica variables
```

Control: autoridad impresa no elimina informantes ni fija taxón moderno.

## Estados de una relación

| Estado | Significado | Representación pública |
|---|---|---|
| observado | el archivo contiene la relación declarada | texto pleno y fuente |
| compatible | más de una ruta explica el dato | alternativas visibles |
| inferido | un puente está apoyado pero no observado directamente | confianza y supuesto |
| no demostrado | falta el puente necesario | límite explícito |
| evidencia contraria | un control debilita la hipótesis | contradicción visible |
| dato ausente | el archivo no conserva la variable | nunca se convierte en cero |

## Matriz de independencia aparente

| Dos evidencias parecen independientes | Dependencia posible | Control |
|---|---|---|
| análisis químico y nombre textual | la identificación moderna guio la lectura del nombre | cegamiento o alternativas taxonómicas |
| dos manuscritos | ambos copian un arquetipo perdido | genealogía de variantes |
| carta e inventario | pertenecen al mismo archivo o edición selectiva | procedencia y enlace explícito |
| regalo y receta | la crónica deriva del texto médico | cronología y dependencia textual |
| oficina y compilación | la compilación es propaganda de la oficina | fuentes administrativas externas |
| Orta y Clusius | Clusius depende de Orta | no contar como corroboración independiente |

## Poder y visibilidad

Los intermediarios no ocupan posiciones equivalentes. Un soberano puede ordenar una traducción; un mercader decide qué transporta; un impresor selecciona formato; un recolector o informante puede aportar identificación sin recibir crédito; una persona esclavizada o subordinada puede ser obligada a mover o revelar conocimiento. La mediación debe registrar agencia y coerción sin deducirlas sólo por categoría.

## Contrato con MED-001 y MED-002

MED-013 reconstruye circulación histórica. Cuando una fuente afirma curación, MED-001 exige comparador, denominador, daños y seguimiento. Cuando identifica enfermedad o sustancia por una señal, MED-002 exige referencia, error y consecuencias. El expediente no convierte la longevidad de un remedio en eficacia ni un nombre histórico en diagnóstico moderno.

## Qué no calcula este mapa

- centralidad cultural;
- “influencia” como puntuación;
- velocidad de difusión sin fechas observables;
- superioridad de un repertorio;
- eficacia por circulación;
- identidad individual desde lengua, religión o imperio.

## Falsadores de la síntesis

La síntesis cambiaría si nuevas asociaciones vincularan carga y uso; si testigos tempranos invirtieran direcciones; si archivos enlazaran envío, preparación y paciente; si oficinas demostraran cobertura poblacional; o si voces de informantes reordenaran autoría. El modelo está diseñado para incorporar esos cambios sin reescribir conexión como progreso.
