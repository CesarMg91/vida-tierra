# Mapa epistemológico — MED-004: del documento a la práctica

## Cadena principal

```text
OBJETO CONSERVADO
tablilla · papiro · ostracon · cuerpo · estela
        ↓ procedencia, fecha material, integridad
LECTURA
signos · restauraciones · traducción · duplicados
        ↓ género y voz
FUNCIÓN DOCUMENTAL
receta · pronóstico · carta · norma · registro
        ↓ circulación y acceso
PRÁCTICA SITUADA
acción, consulta, ausencia, cuidado o transmisión
        ↓ denominador y consecuencia
RESULTADO
cambio corporal, laboral o social observado
```

## Matriz de no herencia

| Si observamos… | Podemos sostener… | No se hereda… |
|---|---|---|
| receta copiada | repertorio textual | preparación, uso o eficacia |
| signo + pronóstico | clasificación histórica | diagnóstico biomédico |
| título de sanador | rol reconocido | tareas rígidas o cobertura |
| ley sobre honorarios | norma jerárquica | aplicación cotidiana |
| carta de consulta | práctica situada | frecuencia poblacional |
| ausencia por enfermedad | morbilidad administrativa | diagnóstico exacto |
| lesión o CT | estado biológico | tratamiento descrito en un texto |
| ingrediente activo hoy | actividad bajo ensayo moderno | efecto de la receta antigua |
| semejanza regional | problema o forma comparable | transmisión o prioridad |

## Dos regiones, archivos no equivalentes

```text
MESOPOTAMIA                         VALLE DEL NILO
arcilla y duplicados                papiro y conservación excepcional
catálogos y colofones               rollos y ostraca
cartas de corte                     registros de trabajadores
series diagnósticas/terapéuticas    casos, prescripciones e incantaciones
        \                           /
         \── circulación situada ─/
```

## Cortafuegos

1. copia ≠ composición;
2. texto ≠ práctica;
3. práctica ≠ frecuencia;
4. receta ≠ efecto;
5. título ≠ profesión moderna;
6. “mágico” ≠ irracional;
7. norma ≠ aplicación;
8. lesión ≠ tratamiento;
9. semejanza ≠ transmisión;
10. primero conservado ≠ invención.

## Casos adversarios

- **Hammurabi:** excelente para norma y jerarquía, débil para aplicación.
- **Nínive:** excelente para corpus y técnica escrita, débil para acceso y resultado.
- **Edwin Smith:** excelente para estructura textual de casos, débil para eficacia observada.
- **Deir el-Medina:** excelente para práctica situada, débil para generalización nacional.
- **empaquetamiento dental ptolemaico:** fuerte como caso corporal raro, débil como prevalencia o profesión.
- **títulos de sanadores:** visibles para élites y varones, silenciosos sobre cuidado doméstico.
