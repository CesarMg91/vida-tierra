# Mapa epistemológico — MED-016: anatomía, disección e imprenta

## Pregunta de control

¿Qué puente permite pasar de un cuerpo situado a una corrección anatómica pública, y dónde debe detenerse la inferencia?

```text
cuerpo disponible
        │  procedencia · poder · estado · selección
        ▼
procedimiento
        │  finalidad · secuencia · instrumentos · manos
        ▼
imagen
        │  mirada · dibujo · talla · composición · escala
        ▼
texto y autoridad
        │  lengua · versión · género · cita · nomenclatura
        ▼
comparación
        │  cuerpos · ediciones · tradiciones · variantes
        ▼
corrección
        │  cambio trazable · justificación · replicación
        ▼
circulación
           ejemplar · traducción · aula · lector · adopción
```

## Matriz archivo–producto–límite

| Archivo | Observa | Inferencia permitida | No hereda |
|---|---|---|---|
| cuerpo o registro de acceso | selección, procedencia y estado | población material disponible | consentimiento o representatividad |
| acta de autopsia | finalidad, participantes y lesión descrita | examen post mortem situado | docencia regular o etiología moderna |
| protocolo o guía | orden normativo de acciones | procedimiento prescrito | ejecución de cada corte |
| dibujo manuscrito | figura, rótulo, soporte y variante | programa visual y copia | disección directa o exactitud |
| xilografía impresa | bloque, prueba y edición | reproducción y variante editorial | mano única o recepción uniforme |
| traducción | elecciones léxicas y equivalencias | mediación conceptual | identidad entre anatomías |
| anotación de autor | cambio propuesto sobre una edición | revisión trazable | adopción o acierto automático |
| registro de cátedra | fundación, titular y acto | capacidad institucional | continuidad, asistencia o práctica clínica |
| manual forense | lista y diagrama para inspección | cuerpo judicialmente operativo | disección académica o tratamiento eficaz |
| catálogo de ejemplares | testigos y lugares conservados | mínimo de circulación | tiraje total, lectura o uso |

## Grafo de mediación visual

```text
cuerpo observado
  ├─ posición y conservación
  ├─ ventana creada por el procedimiento
  └─ variación individual
          │
          ▼
observador ── selección y categorías ──► boceto
          │
          ▼
dibujante ── síntesis y escala ────────► imagen maestra
          │
          ▼
tallador/copista ── inversión y variante ► matriz o copia
          │
          ▼
impresor/editor ── prueba y ensamblaje ─► edición
          │
          ▼
lector/traductor ── uso y corrección ───► nueva versión
```

## Siete expedientes y punto de detención

| Caso | Puente fuerte | Punto de detención |
|---|---|---|
| Manṣūr | testigos + cinco sistemas + genealogía | procedimiento directo y ruta original |
| Bolonia–Berengario | institución + roles + observaciones publicadas | regularidad y experiencia de cada cuerpo |
| Vesalio–Valverde | cuerpos + taller + variantes + revisión | autoría visual exacta y efecto clínico |
| Nueva España | cuatro hitos con productos distintos | prioridad continental y continuidad |
| Itâkî | manuscrito + traducción + comparación de figuras | disección local y recepción |
| *Kaitai shinsho* | demostración + traducción + impresión + revisión | validación total y adopción uniforme |
| Qing | forénsica + trauma + cadáveres expuestos + libro | disección seriada y acierto de cada teoría |

## Estados que deben permanecer distintos

- **observado:** el archivo conserva el objeto u operación declarados;
- **inferido:** el puente está explícito y admite alternativas;
- **no demostrado:** falta una relación necesaria;
- **dato ausente:** el archivo no contiene la variable;
- **evidencia contraria:** una variante o control debilita la generalización;
- **inaplicable:** la pregunta no corresponde al producto.

## Cortafuegos

1. cuerpo disponible `≠` cuerpo representativo;
2. acceso `≠` consentimiento;
3. autopsia `≠` disección docente;
4. corte `≠` observación suficiente;
5. figura `≠` copia directa;
6. naturalismo `≠` exactitud;
7. diferencia `≠` error;
8. impresión `≠` versión estable;
9. circulación `≠` lectura o adopción;
10. corrección anatómica `≠` beneficio clínico.

## Falsadores por familia

| Familia | Evidencia que cambiaría el juicio |
|---|---|
| genealogía visual | testigo intermedio fechado o nota de copia que establezca otra ruta |
| procedimiento | acta, diario o instrucciones que documenten finalidad y secuencia distintas |
| autoría | contrato, boceto o prueba que reasigne dibujante, tallador o editor |
| prioridad | objeto anterior con producto y territorio comparables |
| corrección | comparación controlada que muestre que la variante no mejora la descripción |
| circulación | inventarios, tirajes y marginalia que cambien alcance o recepción |
| efecto clínico | series contemporáneas comparables con intervención, mecanismo y desenlace |

## Regla de salida

Una afirmación sólo asciende si conserva el mismo cuerpo, procedimiento, versión y comparación. Si cambia de cadáver a figura, de figura a edición o de edición a práctica, el denominador y la mediación deben declararse otra vez.
