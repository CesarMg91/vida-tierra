## 1. Grafo principal

```text
objeto / ecofacto / persona / edificio
                 │ procedencia + fecha
                 ▼
             contexto local
                 │ proxy explícito
                 ▼
        conducta o relación delimitada
                 │ serie comparable
                 ▼
           patrón de asentamiento
                 │ controles regionales
                 ▼
            trayectoria regional
                 │ mecanismo demostrado
                 ▼
          interacción entre regiones

Nunca por herencia:
tipo → pueblo → lengua → Estado → civilización
```

## 2. Cinco archivos paralelos

| Archivo | Observación | Inferencia permitida | No heredado |
|---|---|---|---|
| residencia | pisos, arquitectura, comensales, estacionalidad | intensidad/duración local | aldea anual, propiedad |
| producción | plantas, fauna, herramientas, residuos | procesamiento, cultivo o manejo por prueba | domesticación/economía completa |
| pertenencia | entierros, isótopos, ADN | movilidad infantil, parentesco, afinidad | etnia, lengua, ciudadanía |
| urbanismo | superficie, densidad, funciones, flujos | concentración regional | capital, Estado, imperio |
| administración | sellos, fichas, tablillas, almacenes | operación registrada | alfabetización y territorio completo |

## 3. Cadena Ohalo–Dhra’

```text
Ohalo II: estructura + plantas → inversión/uso repetido
                      ⇢ agricultura: no

ʿAin Mallaha: ratones comensales → movilidad reducida
                      ⇢ residencia anual: no

Dhra’: estructura elevada → almacenamiento predoméstico
                      ⇢ propiedad/clase: no
```

Son tres casos, contextos y relojes. Su orden contradice una cadena necesaria; no crea otra cadena universal.

## 4. Cadena del manejo animal

```text
abundancia + edad/sexo + trayectoria temporal
          + sales de orina en sedimento
                        ↓
       animales mantenidos localmente [B-COND]
                        ↓
   domesticación morfológica / pastoralismo
                 [requieren otras series]
```

## 5. Cadena de arquitectura especial

```text
escala + forma + inversión + simbolismo
                  ↓
         edificio extraordinario
          ┌───────┼────────┐
      comunal   ritual   residencial/múltiple
          └───────┼────────┘
       residuos + accesos + secuencia
                  ↓
        función mejor restringida
```

Templo, sacerdocio y Estado quedan fuera sin archivos institucionales.

## 6. Cadena de movilidad y pertenencia

```text
esmalte dental → Sr/O de infancia → local/no local bajo baseline
ADN antiguo   → parentesco/afinidad → relación en muestra
entierro       → tratamiento/lugar  → inclusión o diferencia mortuoria

convergencia posible → pertenencia local condicionada
salto prohibido       → etnia, lengua, ciudadanía, matriarcado
```

## 7. Cadena de urbanismo norte/sur

```text
Tell Brak + prospección regional → concentración septentrional
Uruk + tablillas                 → archivo administrativo local
Lagash + UAV/magnetometría       → densidad y multicentrismo
245 sitios zooarqueológicos      → dependencia rural variable
Shakhi Kora                      → centralización reversible

síntesis: urbanismos conectados y múltiples [B-COND]
no: una cuna que exporta ciudad, Estado y escritura como paquete
```

## 8. Clima sin determinismo

```text
evento climático
   + exposición local
   + cronología de respuesta
   + mecanismo
   + caso negativo
          ↓
causalidad regional evaluable
```

Coincidencia por sí sola sólo produce hipótesis.

## 9. Estados del módulo público

| Estado | Significado |
|---|---|
| archivo | material o medición publicados |
| inferencia | conclusión máxima del caso |
| límite | salto no autorizado |
| tensión | evidencia/modelos favorecen alternativas distintas |
| faltante | el archivo necesario no está disponible |

«Faltante» no se renderiza como cero y «límite» no se confunde con evidencia contraria.
