# 05 — Proterozoico

Oxigenación, eucariotas, endosimbiosis, sexo, multicelularidad, glaciaciones y organismos complejos, incluido el Ediacárico en su secuencia natural.

- [`INVESTIGACION_015_GRAN_OXIDACION.md`](INVESTIGACION_015_GRAN_OXIDACION.md): reconstruye la Gran Oxidación mediante `S‑MIF`, geocronología, meteorización y V/Tl; separa umbral atmosférico, nivel de `pO₂`, plataformas someras y océano profundo.
- [`INVESTIGACION_020_SNOWBALL_EARTH.md`](INVESTIGACION_020_SNOWBALL_EARTH.md): separa depósitos glaciares, correlación global, paleolatitud, extensión del hielo y familias climáticas para las glaciaciones Sturtiana y Marinoana.
- [`INVESTIGACION_021_EDIACARA.md`](INVESTIGACION_021_EDIACARA.md): separa periodo, ventana tafonómica, asociaciones, desarrollo, conducta, ecología y afinidad para una biota que no constituye un solo clado.
